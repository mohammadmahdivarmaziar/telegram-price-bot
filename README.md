# ربات قیمت دلار و طلای ۱۸ عیار تلگرام

ربات پایتونی برای ارسال خودکار قیمت دلار آزاد و طلای ۱۸ عیار هر ۴ ساعت یک‌بار در گروه تلگرام.

ویژگی‌ها:
- دریافت قیمت دلار و طلای ۱۸ عیار از داده‌های عمومی TGJU
- تبدیل ریال به تومان
- ذخیره تاریخچه در SQLite برای رسم نمودار
- ساخت کارت تصویری برای هر دو قیمت
- ارسال عکس + کپشن فارسی
- برداشتن پین قبلی و Pin کردن پیام جدید
- اجرای رایگان با GitHub Actions بدون نیاز به سرور دائمی

## راه‌اندازی

1. یک Bot در BotFather بساز و Token را بردار.
2. ربات را به گروه اضافه کن و Admin کن؛ حداقل اجازه ارسال پیام و Pin کردن پیام‌ها را بده.
3. در GitHub یک Repository بساز و فایل‌های این پروژه را داخلش قرار بده.
4. در Repository برو به:
   Settings → Secrets and variables → Actions
5. دو Secret بساز:
   - `BOT_TOKEN` = توکن ربات
   - `CHAT_ID` = آیدی گروه
6. Workflow با نام `price_bot.yml` هر ۴ ساعت اجرا می‌شود.

### پیدا کردن CHAT_ID
ربات را داخل گروه اضافه کن و یک پیام ساده در گروه بفرست. سپس می‌توانی از یک بات/روش مورد اعتماد برای مشاهده chat_id استفاده کنی، یا بعداً یک دستور `/chatid` به پروژه اضافه کنیم.

### تست دستی
در GitHub:
Actions → Price Bot → Run workflow

## نکته
اولین اجرای ربات فقط چند نقطه برای نمودار دارد. با هر اجرای ۴ ساعته تاریخچه بیشتر می‌شود و نمودار طبیعی‌تر خواهد شد.
